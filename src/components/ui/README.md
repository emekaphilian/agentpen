# AgentPen UI Design System

This folder contains reusable enterprise-grade UI components for AgentPen.

## Design goals

- Dark-first enterprise appearance
- Generous spacing and whitespace
- Accessible focus states and controls
- Modular components built with React and Tailwind
- Premium styling inspired by OpenAI, Stripe, and Linear

## Included components

- Button
- Card
- Badge
- Input
- Select
- Textarea
- Table
- Modal
- Drawer
- Tabs
- EmptyState
- LoadingState
- Skeleton
- Spinner
- Tooltip
- PageHeader
- SectionHeader
- MetricCard
- StatCard
- StatusBadge
